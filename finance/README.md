# Финансовая модель «Пульс продаж»

[Книга Excel](financial-model.xlsx) содержит бюджет внедрения на шесть месяцев, допущения и три сценария годового эффекта. Синие значения в листах «Допущения» и «Бюджет» можно менять в Excel. Формулы пересчитывают эффект и бюджет при открытии книги и после изменения входных данных.

Внедрение стоит **27 170 000 ₸** при лимите **30 000 000 ₸**, из них **17 800 000 ₸** CAPEX и **9 370 000 ₸** OPEX, включая резерв. Базовый сценарий даёт **87 600 000 ₸** годового чистого эффекта, **222,4%** ROI первого года и **3,7 месяца** окупаемости с момента начала получения эффекта. Годовой эффект и ROI рассчитаны на 12 месяцев эксплуатации после внедрения. Прирост от контроля визитов и выручка ларей складываются по модели. Суммы и ставки — допущения для оценки проекта.

Лист «Денежный поток» показывает шесть месяцев внедрения и 18 месяцев эксплуатации по базовому сценарию. Накопленный поток впервые становится положительным на **10-м месяце проекта**. При эффективной годовой ставке **16%** NPV за 24 месяца составляет **82 688 162 ₸**. Потоки дисконтируются на конец каждого месяца по эквивалентной месячной ставке. Лист «Чувствительность» показывает годовой чистый эффект и окупаемость с начала эксплуатации для 15 сочетаний прироста продаж и возврата ларей в продажи.

Для генерации и проверки используйте Python 3.10 или новее. Команды выполняются из корня репозитория.

```sh
python3 -m venv finance/.venv
source finance/.venv/bin/activate
python3 -m pip install openpyxl==3.1.5 formulas==1.3.4
python3 finance/build_model.py && python3 finance/verify.py
```

Генератор использует openpyxl и записывает книгу и `summary.json` для страницы `/finance`. Для изменения обеих версий обновите входные значения в генераторе и запустите его снова. Скрипт проверки отдельно вычисляет формулы книги через formulas и сверяет вывод со сводкой, затем проверяет лимит бюджета и срок.
